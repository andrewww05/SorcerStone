# SorcerStone

Програма рахує найчастіші слова в тексті першої книги про Гаррі Поттера (`src/txt/harry.txt`) і виводить топ 30.

## Запуск

```
java src/Main.java
```

Треба Java 11+. Запускати з кореня проекту, бо шлях до файлу відносний.

## Що я знайшов в старому коді

1. **Баг з пошуком унікальних слів.** Було `distinctString.contains(word)`, а це перевірка підрядка, а не слова. Тому слова, які є частиною інших слів, просто губились. Через це в топі не було `the`, `to`, `he`, `of`, `it`, `in` і ще купи слів. Це найважливіше.
2. **Дуже повільно.** Сортування, склеювання рядка в циклі, потім підрахунок через два вкладені цикли. Це десь O(n * m), де n це всі слова (~80 тис.), m унікальні (~5,7 тис.). Працювало ~2.5 с.
3. **Склеювання рядків в циклі** (`distinctString += ...`). Кожен раз створюється новий рядок.
4. **Частоту зберігали в рядок** (`"word 5"`), а потім витягували число через `replaceAll("[^0-9]", "")`. Дуже криво, краще мапа або окремий клас.
5. **Невикористана змінна** `size`.
6. **Читання файлу** через `new String(bytes)` без кодування. Залежить від системи. Сам файл не в utf-8 (там кривi лапки), тому потрібно вказувати кодування явно.
7. **Все в одному методі**, нема розділення на логіку і вивід.
8. **Шаблонний коментар від IDE** зверху (`${NAME}`, "Default (Template) Project") і код без `class` та імпортів. Працює тільки на новій Java з preview фічами, на звичайній не збереться.
9. **Час через LocalDateTime і ChronoUnit**, хоча вистачає `System.currentTimeMillis()`.
10. **Апострофи.** `didn't` розбивається на `didn` і `t`, тому в топі є `s` і `t`. Я це не чіпав, залишив як було.

## Що я зробив

- Переписав на нормальний клас `Main` з імпортами, тепер збирається на Java 11+.
- Рахую слова через `HashMap` і `merge`, один прохід замість двох циклів.
- Розбив на методи: `splitToWords`, `countWords`, `printTop`.
- Сортую по частоті, а при рівній кількості за алфавітом. Раніше порядок для однакових значень був випадковий.
- Виправив баг з підрядками (п.1).
- Кодування файлу задав явно.
- Забрав зайву змінну, константи `FILE` і `TOP` винесені нагору.
- Час тепер ~300 мс замість ~2500 мс.

## Що ще можна покращити (не робив)

- Додати стоп-слова (`the`, `and`, `to`...), щоб топ був цікавіший і показував `harry`, `ron`, `hagrid`.
- Нормально обробляти апострофи, щоб `didn't` не ділилось на два слова.
- Передавати шлях до файлу і розмір топу через аргументи командного рядка.
- Додати `.idea/` і `*.iml` в `.gitignore`, зараз вони в репозиторії.
- Написати юніт-тести на `splitToWords` і `countWords`.
- Підключити Maven або Gradle.
